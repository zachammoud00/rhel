# 🔴 Red Hat Enterprise Linux

## About

This repository serves as a personal knowledge base for my Red Hat Enterprise Linux (RHEL) studies, with a focus on preparing for the Red Hat Certified System Administrator (RHCSA) certification.

It covers the exam objectives through detailed topic breakdowns, explanations in my own words, diagrams, and practical lab exercises. The goal is to develop a deeper understanding of Linux administration by applying concepts in hands-on environments rather than relying solely on theoretical study.

My primary study resource is *RHCSA Red Hat Enterprise Linux 9 (RHEL 9) Certification Guide* by Sander van Vugt, supplemented by official Red Hat documentation and other resources where necessary.

## 🪾 Repository Structure

The structure of this repository will follow the structure of the certification guide. Each chapter will include explanations, questions and answers, and custom labs to practise and reinforce concepts.
